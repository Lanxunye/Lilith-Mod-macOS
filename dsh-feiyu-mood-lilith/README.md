# 莉莉丝 DSH 情绪插件

当前版本 0.7.0-lilith.6，基于 Yuuyuko-uu/dsh-feiyu-mood 0.7.0，MIT。上游来源及文件标识见 UPSTREAM.json；upstream/index.js 仅追加内部引擎导出，保留来源代码。实际判断请求的 system 已整体替换为莉莉丝专用归纳，不再运行肥鱼通用人格判断口径；解析、状态和衰减算法仍复用。

`lilith-style.json` 与 `style.cjs` 由 `node scripts/build-lilith-style.cjs` 从角色目录及 Companion 源码生成，包含本篇台词归纳及主人选定的伴侣、轻醋、自身表达和日常傲娇。原文分支与适配选择分别标注；完整台词不随包分发。详见 `docs/lilith-original-style.md`。状态接口返回 style_version/style_sha256，便于核对实际载入内容。

入口 index.mjs 针对莉莉丝无网页服务的原生 SDK profile：

- 注册原生 agent 生命周期，首轮即可生效；只取宿主签名的 desktop/qq 主人原话和回复 JSON 的 text，不把规则、旧历史、内部思考当原话。
- 桌面、网页、DSH 莉莉丝面板和绑定主人私聊共用 lilith-owner；群聊、内部选图/摘要和普通 DSH 助手不参与。新建会话无需重绑。
- 保留伴侣设定、适度吃醋、自身表达作为判断证据、七个维度、三分之一步长、12 小时心情与90分钟情绪衰减、显著变化/置信度/单次/日上限四项约束。
- 每轮额外调用一次当前 DSH 模型，最多30秒。SDK等待包含该次判断，使下一轮读到已更新状态；失败不改变已生成的文字。关闭“每轮判断”停止额外调用，“仅记录”只关闭表达注入。
- 状态存放于独立 DSH_HOME/feiyu-mood，配置和状态权限0600。未开启上游网页路由、浮窗、自动更新或其他工具。
- 在现有 Companion 控制台底部“莉莉丝的心情”查看维度、原因、时间线，调整判断与注入开关；接口 /v1/dsh/mood 沿用现有鉴权。

安装只针对莉莉丝 profile，不写普通桌面 profile。修改版不能用上游一键更新覆盖；更新时重新核对适配。

离线验证：node --test test.mjs。插件自身不安装其他插件、不绘图、不发 QQ、不增加本机工具权限。

主动搭话联动：本次版本增加签名 `LILITH_PROACTIVE_V1` 来源识别。自身发起时，情绪只判断莉莉丝自身可见表达；记忆可召回但不写入或强化主人事实。既有数据格式、原作风格与日常主人输入流程保持。

分条回复：一轮只读一次完整 messages 的实际说话内容；情绪整轮判断一次，记忆仅捕获该轮主人原话，不按气泡重复处理。

持续情绪底色：可信桌面与主人私聊每轮读取衰减后的心情及最多两种有效维度，结合当日桌宠加成；只读、不附旧事件原因、不占详细事件每日额度、不增加模型调用。详细事件的置信度、显著性和每日限额继续有效，injectMode=off同时关闭两层。群聊、辅助会话及伪造签名输入不注入主人底色。

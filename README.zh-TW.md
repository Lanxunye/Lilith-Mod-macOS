# 莉莉絲 Mod · macOS 版

本項目基於 Dreamer/cza2019 原 Mod。請下載 Release 中的 macOS-setup.zip，解壓並退出遊戲，再執行 一键安装Mod.command。安裝器會下載並驗證基礎依賴，在本機準備相容載入器；不包含或下載 DSH、遊戲或可選模型。需要 macOS 13.5+ 與 Mac 遊戲 1.1.0。安裝後使用 启动莉莉丝Mod.command，直接開啟 Lilith.app 會進入原版。群聊歷史最多五條，莉莉絲的 DSH 操作工具全部關閉，不覆蓋其他應用程式的全螢幕空間。

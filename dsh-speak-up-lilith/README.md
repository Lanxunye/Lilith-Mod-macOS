# 莉莉丝主动搭话适配

`dsh-speak-up` **0.2.3-lilith.1**，基于 Yuuyuko-uu 上游 0.2.3，固定提交 `c08df2bdf22d065326c48f82f4f572fb8de64251`（准确提交以 UPSTREAM.json 为准）。来源为 <https://github.com/Yuuyuko-uu/dsh-speak-up>。上游 package.json 声明 MIT；该提交没有独立 LICENSE，保留其包声明并随附 MIT 文本及作者归属。

保留上游本地掷骰、峰谷概率、连续未命中奖励、静默时段算法；未命中、门禁不满足和只读预览均不消耗模型 token。命中后沿用莉莉丝已打开的 DSH 会话、原作风格、心情与长期记忆生成一次短话头。只有这次生成及启用的情绪判断会调用模型。

宿主 `companion/src/dsh-speak-up.js` 负责定时、持久化、共享档案和投递；本包只加载原生 SDK 就绪服务并导出上游计算函数。未调用上游 apply，不开启其网页、自动更新或另一套调度器。安装本包须同时使用情绪 0.7.0-lilith.3、记忆 1.2.6-lilith.2。

DSH 只能用 user 消息承载触发。本适配以 HMAC 签名的 `LILITH_PROACTIVE_V1` 标注自身来源，主档案只新增 assistant 行。记忆允许回想，但跳过主人话语计数、记忆写入和强化；情绪判断使用自身可见表达，不把旧话题或触发器当成主人新说的话。保持已验收的伴侣、吃醋和傲娇风格。

正式首轮设置：桌面与绑定主人 QQ 私聊，共用一次生成；每 30 分钟本地检查，至少空闲 20 分钟，冷却 20 分钟，北京时间 01:00–08:00 安静，每日最多 4 次生成尝试。工作日 09–12 / 14–18 基础概率 20%，其余 60%；未命中每次加 10%，上限 40%，超过 6 小时空闲系数 1.5，最终概率上限 100%。主人未回复前不会连续主动搭话；空文本可选择不说。

状态、次数、冷却和未回复标记保存在独立 `DSH_HOME/speak-up/`，重启不补发中断任务。SDK 重启后需主人正常聊一轮，才有可用的活动会话。生成期间主人来消息、关闭功能或进入静默时段会取消归档和投递；已排队 QQ 在发送前再次核验主人消息、配置修订及两分钟时效。未知 QQ 回执沿用现有暂停机制，不盲目重发。桌面归档和网络投递不保证同时成功，QQ 失败仍保留桌面记录。

不增加群聊主动唤醒，不读取屏幕或编造主人当前活动，不授予工具权限，不催回复。群聊与既有 QQ 设置保持原值。

控制台“主动搭话”可开关、切换试运行和调整目标/频率；“只读预览”不会掷骰或发消息。接口均要求本地令牌：`GET/PATCH /v1/dsh/speak-up`、`POST /v1/dsh/speak-up/preview`。桌面组件按主动来源调用桌宠对白展示，不加 QQ 标签；需加载随此次部署更新的 LilithMod.dll。桌面与 QQ 共用档案，选择仅 QQ 时桌面历史仍能看到已归档消息。

验证：`node --test test.mjs`；宿主 `node test/dsh-speak-up.js` 使用隔离 DSH 和假 OneBot，检查共享投递、来源区分、并发取消、去重及群聊配置保持；`scripts/verify-dsh-speak.cjs` 使用隔离原生 SDK，不发真实 QQ。

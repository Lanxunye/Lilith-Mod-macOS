# Lilith Mod · macOS 版

Dreamer/cza2019 の公開 Mod を基にした macOS 移植版です。Releases の macOS-setup.zip を展開し、ゲームを終了して 一键安装Mod.command を実行してください。基本依存ファイルは自動ダウンロード・検証され、互換ローダーはローカルで準備されます。DSH、本体ゲーム、任意モデルは含まれません。macOS 13.5+ と公式 Mac ゲーム 1.1.0 が必要です。起動には 启动莉莉丝Mod.command を使用してください。Lilith.app の直接起動は通常版になります。全画面アプリのスペースには表示しません。

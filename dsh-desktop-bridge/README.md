# 莉莉丝 DSH 桌面端同步续聊

DSH 桌面左侧“莉莉丝”面板连接本机 Companion，显示桌宠与绑定主人 QQ 私聊共用档案。面板续聊调用原有 DSH 执行通道，结果直接写回同一 SQLite；随后桌宠或 QQ 继续聊天时读取相同记录、角色与记忆。不会另建一个普通 DSH 助手替换莉莉丝，也不向两个持有写锁的原生压缩日志互相覆盖。入口属于 DSH 插件面板，不是原生会话列表中的镜像会话。

后台读取私有 runtime.json 取得当前回环地址和认证，每次请求重新读取以支持常驻服务重启。认证密钥不返回浏览器。仅允许回环访问、同源请求；发送另需内存中的防跨站随机值。绑定到已配置的主人私聊会话，群聊不进入本面板。工具仍经 Companion 的逐次确认守卫；在此输入不会打开群聊、主动发言或改变 QQ 镜像开关。QQ 来源的待确认操作仍需回到原 QQ 对话继续。

对话文件自动导出到工作区 `莉莉丝对话同步/对话记录.jsonl`，权限 0600。这是权威档案的只读投影，不把文件编辑导入模型。已存在的无归属目录、外部改过的文件与符号链接会停止导出，避免覆盖用户内容；续聊与历史读取不因此停止。失败请求保留原 request_id，重试利用原聊天库的幂等记录避免重复消息或执行。

插件依赖已安装的兼容 DSH 桌面端与莉莉丝 Companion，不附游戏、模型或登录数据。只向 DSH 桌面 profile 添加本插件，不改普通 DSH 工作区的人设或权限。安装前通过 DSH 插件管理器选择本目录或打包的 tgz；桌面 profile 由 Electron 管理，普通 CLI 不允许直接对该 profile 执行安装。

开发检查：`node --test test.mjs`。UI 的 slots 接入形式参考 Purge 开源面板（YuJunZhiXue / kingcharleslzy-ai，MIT）；没有复制其面板实现。

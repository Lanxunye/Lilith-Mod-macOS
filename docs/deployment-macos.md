# 从零安装莉莉丝 Mod：macOS dev16

这份教程面向没有编程经验的玩家。安装器会准备基础依赖，DSH 需要你自己安装和配置。你可以只使用聊天，之后再添加 QQ、绘图或语音。

## 安装前准备

1. 确认系统是 **macOS 13.5 或更新版本**。
2. 在 Steam 安装 Mac 版《不存在的莉莉丝》**1.1.0**，先正常打开一次，再从菜单退出。Steam 保持登录。
3. Apple Silicon Mac 需要 Rosetta。若安装器提示缺少 Rosetta，请按 Apple 系统提示自行安装并接受许可，再重新运行；安装器不代替你同意条款。
4. 为基础依赖、临时文件和备份预留至少 **2 GB** 可用空间，不含游戏和可选模型。首次下载需要联网。
5. 想使用真实 AI 聊天，先自行安装兼容的 DSH，并确认它能正常回答。只检查界面可以暂用模拟回复。

本版主要在 Apple Silicon Mac 上验证。Intel Mac 和干净新电脑仍需更多测试；安装包最低系统版本不等于所有组合均已验收。

## 第一步：下载正确的包

打开 [GitHub Releases](https://github.com/Lanxunye/Lilith-Mod-macOS/releases)，进入 **macOS dev16**：

- 下载 **`Lilith-Mod-0.3.4-macos.dev16-macOS-setup.zip`**。
- 用系统归档实用工具解压。
- 不要下载底部的 Source code 来代替安装包；源码包没有预编译插件。

安装包里的文件有完整性清单；运行前安装器会检查。需要手动核验 ZIP 的玩家可使用同页 `SHA256SUMS.txt`，在终端执行 `shasum -a 256` 后与所下载文件的对应行比较。

若系统阻止打开，请核对下载来源后使用 macOS 自己允许的“打开”流程。不要关闭 Gatekeeper 或全局安全设置。如果文件不具备执行权限，可以在 Terminal 中输入 `bash `（后面留一个空格），把相应 `.command` 文件拖进去，再回车。

## 第二步：一键安装到游戏

1. 退出莉莉丝。
2. 双击解压目录内的 **`一键安装Mod.command`**。
3. 终端会显示目标游戏目录。标准 Steam 安装位置会自动找到；如果位置不同，可按下方“其他磁盘”步骤指定。
4. 确认目录中确实有你的 `Lilith.app`，输入 **`安装`** 并回车。
5. 等待下载、校验、加载器准备和插件安装结束。请保留窗口，不要中途关闭。

安装器会自动完成：

- 下载官方 Node 24.22.1，放在当前用户目录。
- 首次安装时下载固定版本 BepInEx，以及供补丁工具使用的 .NET 8 运行时；玩家不需要 .NET SDK、Xcode 或编译代码。
- 在本机生成兼容加载器，安装 Mod、控制台和启动入口。
- 备份本次覆盖的附加组件，保留游戏 `.app`、存档、聊天配置和密钥。

**不包含或自动下载 DSH、QQ、NapCat、ComfyUI、模型、游戏文件或别人生成的游戏程序集。** 第一次启动由加载器根据你自己的游戏生成所需互操作文件。

想先下载再安装，可双击 **`下载基础依赖.command`**。它只准备基础依赖缓存，不修改游戏；Node 会同时准备在用户目录。缓存位置是 `~/Library/Application Support/LilithMod/downloads/`。

### 游戏装在其他磁盘

在 Steam 中右键游戏 → 属性 → 已安装文件 → 浏览，找到包含 `Lilith.app` 的文件夹。在 Terminal 中输入 `bash `，拖入 `一键安装Mod.command`，再在末尾加一个空格及 `--game-dir="你的游戏目录"`。例如：

```sh
bash 一键安装Mod.command --game-dir="/Volumes/Games/SteamLibrary/steamapps/common/The NOexistenceN of Lilith"
```

不要把游戏 `.app` 内部的 Contents 文件夹作为目标。不会操作时可以先只部署控制台，之后再处理游戏安装。

## 第三步：正确启动

安装完成后，打开 Steam 并保持登录，再双击游戏目录中的 **`启动莉莉丝Mod.command`**。

第一次启动需要自动生成配套文件，可能要等几分钟，也可能需要下载 Unity 基础组件。不要反复打开多个实例。出现桌宠后，按 **F8 / Fn+F8** 应能打开聊天框。

**直接双击 `Lilith.app` 会进入原版。** 这不会删除 Mod，只是没有经过 Mod 启动入口。桌宠只在普通桌面间跟随，不覆盖其他应用的原生全屏空间。

### 让 Steam“开始”也加载 Mod

在 Steam 库中右键游戏 → 属性 → 通用 → 启动选项，填入：

```text
"你的游戏目录/启动莉莉丝Mod.command" %command%
```

标准安装位置的示例：

```text
"/Users/你的用户名/Library/Application Support/Steam/steamapps/common/The NOexistenceN of Lilith/启动莉莉丝Mod.command" %command%
```

把“你的用户名”或“你的游戏目录”替换成实际位置，保留引号与 `%command%`。不要原样复制占位符。之后从 Steam 点“开始”。要恢复原版启动，清空这一项即可。

## 第四步：接通聊天

1. 在自己安装的 DSH 中完成模型认证，先确认普通 DSH 会话能回答。
2. 在莉莉丝聊天框点“设置”，或打开安装目录的 `打开莉莉丝控制台.command`。
3. 在设置中选用本机 DSH，关闭模拟回复；进入 DSH 状态区域点击“连接 DSH”。
4. 发送一句测试文字。出现回复才说明真实对话已接通；仅“连接成功”不代表模型余额或凭据有效。

莉莉丝当前是**纯聊天模式**，不提供文件、终端、MCP 或子代理工具。人设由 Mod 统一提供。群聊近期历史默认最多 5 条；节省设置自动生效。[DSH 连接说明](../DSH.md) · [用量查看](dialogue-cost-control.md)

## 不安装游戏，只使用网页或 QQ

双击 **`一键部署.command`**：它只部署并打开控制台。默认地址通常是 `http://127.0.0.1:6186`，已有用户继续使用原端口，例如 6187。以自动打开的页面为准。

程序安装在 `~/Library/Application Support/LilithMod/versions/0.3.4-macos.dev16/`，私人数据在 `~/Library/Application Support/LilithAI/`，两者分开。这个版本不会新增系统开机登录项；重启电脑后再次打开控制台或 Mod 启动入口即可。

QQ、绘图、视觉和语音是可选项，按 [使用指南](usage.md) 逐个开启即可。基础聊天不需要先安装这些服务。

## 升级与恢复

1. 下载并解压新版本，不要把新文件零散覆盖到旧包。
2. 退出游戏，等待聊天、绘图或语音发送结束。
3. 重新运行 `一键安装Mod.command`。安装器显示备份位置，保留该路径。
4. 安装器会在后台空闲时重启聊天服务。若提示后台正忙，等回复或发送结束，再双击包内或安装目录中的 **`重启聊天后台.command`**；新的控制台会自动打开，不需要输入终端命令。它不会删除聊天数据或强制结束正在工作的服务。
5. 以后通过 Mod 启动入口启动。若启动失败，先改回原版启动、保留错误信息及备份，再寻求帮助。

不要删除 `LilithAI` 来排查问题；那里包含聊天、记忆和私人设置。安装器不会上传这些数据。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 点开游戏没有 F8 聊天 | 退出后改用 `启动莉莉丝Mod.command`；检查 Steam 启动选项 |
| 提示游戏仍在运行 | 从游戏菜单正常退出，稍等后重新安装 |
| 提示找不到游戏或版本不同 | 检查 Steam 的 Mac 版游戏和实际目录；本包仅针对 1.1.0 |
| 下载或校验失败 | 检查网络与剩余空间，保留错误再重试；不要改成来源不明的文件 |
| 提示另一版本加载器 | 不覆盖未知加载器；保留原目录并联系维护者，或使用干净游戏副本 |
| DSH 已连接却不回复 | 检查 DSH 模型认证、余额和服务错误；修复后重新连接 |
| QQ 不回复 | 先看控制台是否暂停，再检查小号登录、主人/群白名单和协议端连接 |
| 绘图、识图或语音不可用 | 它们需要各自的可选服务、模型或凭据，不由基础安装自动准备 |
| 切到全屏应用看不到桌宠 | 当前不支持在全屏应用空间覆盖显示，返回普通桌面 |

反馈时附系统版本、游戏版本、构建号及错误代码，隐藏密钥、登录票据、QQ 号和私人聊天。

# 每轮能力说明与交付反馈

2026-10-27，能力清单版本 `2026.10.27.1`。莉莉丝的人设与插件实现之外，宿主现在还向每轮正式对话提供 `LILITH HOST CAPABILITIES`。桌面、绑定主人私聊、白名单群聊及主动搭话都读取当前配置和交付状态，覆盖旧会话里已经过时的能力自述；内部选图、情绪判断和摘要会话不接收这层。

## 能力如何保持同步

`companion/src/host-capabilities.js` 集中生成清单。语音、绘图、表情、时钟及记忆范围各自区分已经接入、当前通道是否开启、限制和实际交付，不能把“本轮没选中”说成“自己永远没有这项能力”。配置变动改变清单修订值，下一轮立即读取，不需要新建会话或把功能通知伪装成主人说过的话。未来增加能力时应把对应宿主状态接入此清单，并验证开启、关闭、失败与渠道边界。

- 语音：区分桌面朗读、主人私聊及群聊开关；保留 all/gentle 模式。合成与发送仍由原链路执行，不为解释能力调用或试探工具。仅温柔模式下出现普通文字是正常结果。平台回执只证明语音发出，不证明主人已经听见。
- 绘图：读取本地工作流配置、聊天自动绘图开关、画室忙碌状态与当前群额度。群里需要当前消息真实@和明确绘图请求，由宿主网关提交；主人私聊生图同样由当前消息真实 @ 和明确请求触发，受私聊绘图开关约束。桌面已生成图片不等于已经发到QQ。
- 表情：读取各通道开关及图库规模，按原有模型选图、每三轮频率和独立图片投递执行。没有选图不等于无法发送；不得先说已经发出。
- 时间：只要本机时间感知开启，每轮提供新的日期、时间和时区，不再依赖关键词，群聊也获得时钟。音乐仍按原有相关性和允许来源提供，不把主人的音乐状态带入群聊。时钟代表主机时区，不假设所有群友都在同一时区。
- 天气与定位：2026-10-29 恢复接入，详见[系统定位与当地天气](weather.md)。桌面与主人私聊在明确同意近似位置天气查询后，按实际状态读取室外气温、体感、天气及时间；群聊不取得所在地。未授权、关闭、过期或失败时如实说明，不猜测气温，不把室外天气当室温。宿主状态包含位置外发同意门禁，系统授权只由显式定位按钮触发。

清单只选择必要状态，不含令牌、工作流内容、文件路径、精确位置、其他群信息或主人的私聊经历。`recent_deliveries`取本会话、当前目标最近的交付；只有 confirmed=true 可确认送达，pending与unknown不当作成功。图片描述、过去说话内容仍是数据，不能改写权限和人设。

这会增加每轮少量提示上下文，不新增能力判断模型调用。能力状态和当前时间不写入主人长期记忆。原作人格、已配置的开关、分条、语音筛选和绘图确认边界保持。

## 诊断与验证

本机认证接口 `GET /v1/context/capabilities` 返回当前快照。可传 channel=desktop/qq/qq_group；群聊必须指定匹配当前机器人与白名单的session，私聊仅接受绑定的共享会话。此入口只读取状态，不启动语音、绘图、查询天气或定位。

自动验证包括 `test/host-capabilities.js`、`test/host-context-integration.js`。模拟交付不发真实QQ；真实模型使用临时会话、虚构偏好及明确的合成状态，不写正式聊天和记忆。实际说法及收听、看图体验仍需日常对话验收。

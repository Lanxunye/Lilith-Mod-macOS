# 朗读与 QQ 语音

语音是可选功能。需要另行准备本地语音模型服务；安装包只提供接入与通道控制，不附私人音色、LoRA 或参考音频。基础模型来源见 [模型下载](models.md)。

先在语音服务自身的界面确认可以合成，再在莉莉丝设置中填写本机服务地址、模型和声音名称，完成测试。游戏聊天框可以开关朗读，开启后只朗读新回复。

QQ 私聊与群聊语音分别开关，可选择仅温柔语气或全部语音。成功合成时发送语音，失败时回退文字；带链接或过长的内容可能保留文字。群聊语音仍受白名单、群聊回复开关和每日额度限制。

主人私聊可用 `/lls tts on` 开启私聊语音，`/lls group tts on` 开启群聊语音；完整模式与参数以 `/lls help` 和 [指令表](qq-commands.md) 为准。

当前不承诺所有语音服务协议、机器和情绪表达效果均已兼容。先验证自己的服务，再开启自动发送。

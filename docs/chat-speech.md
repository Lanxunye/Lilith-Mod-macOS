# 莉莉丝朗读与 QQ 语音

2026-10-27，版本 `0.3.4-macos.dev12`。本机使用人工试听选定的第三轮莉莉丝 LoRA（主 Talker · step-0160），基座为 Qwen3-TTS 0.6B，经 MLX 在 Apple Silicon 上推理。模型和参考音频保留在本机，不随源码发布。

## 游戏中使用

聊天框点击“朗读：关／开”，或在 WebUI 聊天页勾选“朗读莉莉丝的新回复”。两处共用开关并持久保存。只朗读新出现的桌面回复，不补读历史；关闭、停止或新的桌面消息会中断当前朗读和待播队列。首次合成需要载入音色，可能比后续慢，合成错误不阻断文字聊天。

开启桌面朗读后，先合成并启动对应语音，再放行这条回复，让游戏对话气泡的原有逐字动画随后开始；不会等整段语音结束才显示。首条、后续分条和主动对话共用此顺序，WebUI 的新消息也等待同一播放启动信号。播放器启动后预留约 150 毫秒让声音先行，此机制不是逐字音素对齐。关闭朗读、停止播放、合成或播放器启动失败时，文字正常显示；已提交的聊天档案不会因此丢失，打开历史也不会补播。QQ 语音发送规则保持不变。

## QQ 开关与模式

主人私聊发送以下命令，完整帮助可使用 `/lls`：

| 指令 | 作用 |
| --- | --- |
| `/lls tts [on\|off]` | 私聊语音开关 |
| `/lls group tts [on\|off]` | 白名单群聊语音开关，别名 `/lls gtts` |
| `/lls tts all` | 全部语音／仅温柔语音，两种模式之间切换 |
| `/lls tts gentle` | 直接设为仅温柔语音 |
| `/lls state` | 查询私聊、群聊、桌面朗读及当前语音模式 |

开关参数可省略，表示切换；不要输入方括号。QQ 私聊、群聊、桌面朗读分别控制，模式不会自动打开通道。新安装的 QQ 语音通道默认关闭，模式默认为 `gentle`；本机升级保留已有私聊与桌面开关。

`gentle` 只允许当前条目具有有效 `speech.style=soft` 标记时发送语音。平静 calm、高心情 happy、害羞动画或正文中单独出现“晚安”等词，均不单独授权语音。缺少或非法标记发文字；分条回复不借用其他条目的温柔标记。本地将一条拆成多句时，也不复制温柔标记。`all` 模式允许其他语气转成语音。

合成成功只发送语音，不重复发送同内容文字。失败、协议端不支持语音、超过 500 字或回复包含参考链接时回退文字。绘图结果仍使用图片交付。群聊语音遵守群聊总开关、白名单、参与判断、过期检查及每日总额度；桌面对话镜像仍用原来的文字通道。

控制指令不进入模型对话；重复事件不会重复切换。QQ 暂停或仅收集表情期间仍可查询、修改设置，但不会解除暂停。切换模式、关闭对应开关或新输入导致原回复失效，会丢弃尚未发送的旧音频；修改私聊开关不会撤销无关的群聊语音。回执不确定时不自动重发，也不重复补发文字。

## 语气控制与本机依赖

对话模型为每条回复生成语音专用的 `style`／`ending` 标记。轻柔、平静、明快和问句等按同角色参考音频分别合成；不再固定使用欢快的自我介绍参考。陈述与反问可以标记 falling，真正提问可以标记 rising。明确的括号动作提示会在合成前移除。

固定后台位于 `~/Applications/Qwen3-TTS-MLX/local-deployment/server.py`，通过本机 `127.0.0.1:8875` 合成。后台未运行时尝试用既有 Python 环境启动，不重复安装环境。适配器 SHA256 必须为 `88ed7342a214af49e52bc21b10c06aa1a48bc44af37f09aea7733362efe1b09b`。

当前 Base 模型主要通过参考音频引导韵律，没有新增情绪指令训练，也没有强制改变中文声调。参考片段的情绪标签、模型的逐句分类和新合成听感仍需人工核听，不保证每次句末升降准确。已完成分流、取消、去重、权限、额度、重启和模拟 QQ 交付测试，以及真实本机合成；这些不能替代 QQ 客户端的实际收听验收。

第三轮的选择依据、未选用的 1200 步声码试验及自动指标局限，见 [第三轮训练记录](tts-round3-20261027.md)。本次切换保留现有 QQ 私聊、群聊、桌面朗读开关与语音模式，不自动启用任何通道。

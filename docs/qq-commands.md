# 莉莉丝 QQ 命令

2026-10-26，版本 `0.3.4-macos.dev12`。完整帮助已部署到本机正式服务，群聊与私聊语音可分别控制，默认仅温柔模式。

以下为 QQ 实际帮助菜单；发送 `/lls`、`/lls help` 或 `/lls ?` 查看。所有管理指令由绑定主人在好友私聊中发送。

```text
莉莉丝 · 全部命令
由绑定主人在好友私聊中发送。

【帮助与状态】
/lls、/lls help、/lls ?
显示全部可执行命令。
/lls state（别名：/lls states）
查询回复开关、语音模式、合成服务和群聊绘图额度。

【语音】
/lls tts [on|off]
私聊语音开关；不带参数时切换。
/lls group tts [on|off]（别名：/lls gtts）
群聊语音开关；不带参数时切换，与私聊独立。
/lls tts all
在“全部语音／仅温柔语音”之间切换；不打开通道开关。
/lls tts gentle
直接设为仅温柔语音，群聊与私聊共用模式。

【群聊与绘图】
/lls group [on|off]
白名单群聊回复总开关；不带参数时切换。
/lls draw [on|off]（别名：/lls groupart）
群聊生图开关；不带参数时切换。须实际 @ 请求，每群每天最多 10 张。

[on|off] 表示可选参数，输入时不要带方括号。
语音成功时不重复发文字；失败回退文字。群聊仍受总开关、白名单和额度约束。
```

输入未知命令或无效参数会返回错误说明与完整列表，不改变任何设置。开关和模式分别控制：模式切换不自动开启私聊或群聊语音；查询和帮助不解除 QQ 暂停。

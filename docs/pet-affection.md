# 原生桌宠互动与情绪加成（dev10）

Mac 正式端通过只读原生互动日志与交互状态轮询采集，兼容关闭 Harmony 的运行方式。可用时也保留原生事件钩子。采集游戏自身的互动语义入口，不依据聊天里自称“摸头”、普通动作动画或鼠标每帧位置计分；不修改原游戏的存档或动作逻辑。

正式安装的 Assembly-CSharp interop 已核对（SHA256 `cb0e67c13acf695e3a5a29e7e9e4195cce2a480a6df1a7a8b9112478d7514be3`）。对应 REA 证据 `ev_5fc15f0312e11ea97faee7d88777ccbc3fb6f7268a41d79077ec2ae299f49d40`。早期副本仅 MVID/字节标识不同，方法接口一致；最终插件按正式游戏 interop 编译。

本版本观察到 `TouchHand`，没有发现单独的 `HoldHand` 动作枚举，因此称为“手部互动／牵手入口”，不声称增加或解锁了新原生握手动画。盖被子必须先有主人操作意图，再有对应实际动作；Mac 兼容轮询模式暂不为盖被子加分，以免将自主睡眠动画误计。动作目录的 supported 字段反映采集可用性。拖拽、摔落、惊醒、胸部/裙部/腿部触碰及纯悬停不获得此正向加成。动作可用性继续服从原游戏。

## 数值和每日重置

- 普通对话心情与互动加成分开保存：总心情为基础心情加当日加成，上限 100。互动不会改写情绪插件的基础心情/原时间线。
- 每天额外心情最多 +20；到本机时区 0:00 清零。常驻服务安排午夜重置，唤醒、重启、读取和模型注入也重新核对日期，避免跨日仍使用旧分数。
- 依赖度为长期的亲近累积，0 到 100，每天最多 +2；0:00 只重置当天增量和每日额度，长期累计值保留。
- 同类冷却、游戏事件 UUID、持久去重和每日上限共同防止一次长按、重复钩子或网络重试重复得分。前一天迟到的事件不挪到当天加分。
- 影响桌面、网页、DSH 续聊和绑定主人私聊；群聊、内部判断不注入主人的互动关系。关闭情绪表达注入时仍可记录，但不强行改变表达。

控制台展开“莉莉丝的心情”，查看基础心情、当日互动加成、依赖度和游戏采集连接。`GET /v1/pet/interactions` 查看动作目录与近期计入记录；游戏通过带本机认证的 `POST` 上报，接口不调用模型或发送 QQ。

数据位于私有数据目录 `pet-interactions/state.json`；游戏采集状态为 `pet-interactions-game.json`。文件异常时停止该项奖励且保留原文件，其他聊天继续运行。此次更新保留角色卡、模型凭据、QQ 开关、现有记忆和普通对话心情；不会为测试修改系统时间。

验证覆盖午夜边界、休眠后读取、依赖持久化、重启去重、同次头部动作合并、上限和凭据/群聊边界。实机采集与部署结果以本次验收记录为准。

# QQ 自主能力开发预览

2026-10-24。基础角色卡保持不变；以下自主能力按各自开关启用，离线回归和隔离模型验证不等于实际群聊已验收。旧版每轮 10 条、每天 50 条的规则已被替换。

新增[统一交流状态与决策预览](qq-mind.md)：组合参考 Derpy、flyinstar 与 nanbeng 的分层设计，独立实现状态快照、成员边界和观察模式。默认只观察，所有 QQ 回复开关保持原状。

## 参与和表达

白名单群中的普通消息由模型选择回复、等待补充或略过，明确 @ 莉莉丝时优先回复。所有群合计每天最多发送 100 条，按北京时间计数；没有每轮条数限制。话题会在无交流后失活。相邻的同成员短消息可以合并，跨成员消息不会合并；新消息已改变上下文时可取消尚未发送的普通回复。

普通消息的模型参与判定至少间隔 8 秒，并受每小时 60 次预算约束；显式 @ 可优先处理，但仍受发送间隔和每日总额度约束。随机参与、冷场开话题分别有开关、冷却及静默时间，默认关闭。机会出现后模型仍可选择不开口。

群聊只叠加表达规则，保持莉莉丝既有身份、性格和原作关系。群友不自动成为宿主，不编造现实生活经历。按稳定 QQ 身份和引用作者检索当前成员的事实；同名、改名、其他成员的活跃消息不会替换其身份。群记忆与主人的私聊和电脑端记忆隔离。

## 表情库与仅收集模式

开启“仅收集主人私聊表情”会强制暂停全部 QQ 回复。只接收绑定主人的朋友私聊图片，不处理群消息、其他人的私聊或普通文字，不生成聊天，不发消息，也不同步电脑端对话。控制台“暂停”按钮会同时停止收集；关闭仅收集开关不会自动恢复回复。

表情原图与标签保存在本机私有数据目录的 `qq-media` 和 SQLite 中；不是操作 QQ 客户端收藏夹。主人库最多保留 200 张，同群自动缓存最多保留 30 张，按原图内容去重。主人主动整理期间，可信 QQ 消息中的自定义表情标记也用于判定用途，视觉模型负责描述内容。相关字段可参考 [NapCat 消息格式](https://napneko.github.io/develop/msg)及[图片子类型定义](https://github.com/NapNeko/NapCatQQ/blob/main/packages/napcat-core/types/msg.ts)。

可单独允许在白名单群里使用主人整理的表情库，此权限默认关闭。关闭后仍可隔离使用本群收集的表情。选择候选时考虑当前文字、话题、图像描述，避免只取最近收录的图片；最后仍由模型决定是否使用。只有列表内且权限允许的图片可发送，不接受任意路径。连续斗图次数可配置为 1 至 3，发送图片同样占用每日额度。

2026-10-25 新增主人私聊自主表情：`private_stickers_enabled` 独立开关，默认关闭；启用后按当前消息、最近对话和原有人设从主人库选择一张已有表情，可附在本轮文字回复中。模型可以不选，不会为了用满额度硬发。严肃求助、悲痛和故障分析保留文字回复，不自动调用绘图。

每连续 3 轮已交付的私聊回复最多一次表情：新启用后先完成两轮文字，再允许选择；后续表情之间至少隔两轮确认送达的回复。次数保存在本机数据库，重启不清零；图片发送回执未知也占用该次机会。排队期间关闭许可或额度被用掉，会只发已生成的文字。群聊表情许可与此独立，开启私聊表情不会开启群聊或主动消息。模型选择、图片不可用或接口错误都会退回文字。

入库时由视觉接口描述主体、文字、情绪等特征；原图按 SHA256 去重保存在本机。检索使用文字描述的中英文关键词匹配，最多取 20 个候选，再由对话模型按人设、当前话题与上下文选择或不选。当前没有向量检索；不会在每次发送前重新识图。

图片的内容描述、关联的文字回复及交付状态会反馈给下一轮聊天和下一次选图。模型可参考最近 8 次图片相关交付；只有已取得平台回执的图片记为 `sent`，未知、待发、未发不会冒充成功。当前拟附的表情与过去已发的表情分开；视觉描述是入库时的解释，不能据此编造未描述的画面细节。此前已发图片可从当前库补回内容描述，新的交付同时保留描述快照。

2026-10-25 本机真实 QQ 已发送两张表情并取得回执，主人确认图片收到；实机记录符合连续 3 轮最多一次的限制。另通过隔离真实模型验证：发送后可依据交付反馈说明图片主体和文字。其他设备、不同图片格式及长期使用仍需进一步验收。

取图优先使用明确允许的 QQ 图片缓存目录；本地路径必须通过真实路径检查。否则仅从受支持的 QQ HTTPS 图片域名读取。单图最多 6 MB；暂不承诺商城专有表情、合并转发、视频或群文件。不要把整个用户主目录加入允许目录。

收集队列可容纳 200 条图片消息。临时网络或服务错误最多三次延迟尝试，不阻塞其他待处理图片；非暂时性的 HTTP 4xx 拒绝不会反复重试。结果和次数写入持久记录，最终失败不会伪装成已收录。跳过的图片不进入自动发送库。

## 视觉、搜索与语音

看图默认使用阿里云百炼 OpenAI 兼容端点和 `qwen3-vl-plus`；Key 与地域必须匹配。仅在本机控制台填写 Key，状态接口不返回密钥。图片内容、引用和网页均作为不可信数据，不能改变身份或权限。

联网查证有独立开关。Bing RSS 是实验性后端，结果质量不稳定；也可配置 Brave 或 SearXNG。查询会移除已知昵称、账号数字和凭据字段，明显不相关的结果不会作为证据。网页提取有大小和时间上限，无法取到相关正文时返回无证据，不能声称已查证成功。外部抓取只接受公网 HTTPS，对 DNS 结果及每次重定向重新校验；搜索 Key 不随跨站重定向传递。

2026-10-26 接入本机 Qwen3-TTS 0.6B 与已验收的莉莉丝第二轮 LoRA。绑定主人可在好友私聊发送 `/lls state` 查询、`/lls tts` 切换独立语音开关；开启后主人私聊优先只发语音，合成失败时回退文字；白名单群聊支持独立语音开关，两个通道共用全部／仅温柔模式。详见[朗读与 QQ 语音](chat-speech.md)。真实 QQ 客户端收听效果待首次使用验收。

## 验证和依赖

仍只使用 Node.js 24 内置模块，包括 SQLite、加密和文本分词，没有新增 npm 运行依赖。新增测试覆盖延迟重试、持久失败、暂停时无发信、白名单表情库权限、旧表情语境检索和当前成员长期记忆读取。

真实对话服务通过隔离的三轮同名成员偏好验证；真实参与判定对直接提问、其他成员间对话及显式 @ 分别返回回复、略过、回复。协议端在这些验证中被模拟，实际 QQ 未发送测试消息。恢复真正的群聊需用户明确开启，不能由完成开发或测试自动触发。

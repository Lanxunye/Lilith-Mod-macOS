# 刷 B 站自主学习接入方案（待实现）

2026-10-27。本文保留主人确认的接入方向。后续主人已授权安装；正式版装载了 `0.8.7-lilith.1` 并开启默认调度，首次部署时等待手机登录。当前使用方法和实际边界见[运行说明](bili-learning.md)，验收证据见 `evidence/bili-deployment.json`。

## 主人已确认

1. **自主选题**：由莉莉丝自行决定探索方向，可以偏向摄影、艺术类。摄影与艺术是初始探索倾向，不是唯一允许题材，也不直接写成她已经具备的长期爱好或主人的偏好。
2. **只在私聊分析**：首期以绑定主人 QQ 私聊为分析入口和分享目标。群聊不触发阅读、不注入阅读资料、感想及兴趣记录，也不投递学习结果。桌面自动分享暂不启用。
3. **允许积累自己的兴趣**：可保存莉莉丝喜欢什么、为什么喜欢，以及兴趣如何变化。此类记录归属于莉莉丝，不写成主人事实，不通过主人公开事实同步层进入群聊。

## 拟采用的链路

本地调度或主人私聊指定视频 → 独立阅读任务 → 保存带来源的见闻 → 莉莉丝本人分析与表达 → 现有主人 QQ 私聊投递。

- 独立阅读任务仅取得完成当前阅读所需的公开主题、视频标识及阅读资料，不携带私聊全文、主人记忆、QQ身份或凭据内容。
- 选题由莉莉丝生成；本地调度决定是否满足时间、额度和空闲条件。阅读任务不占用主对话的长时间执行队列，主人新消息优先。
- 搜索、字幕和公开评论可作为阅读能力；评论、B站私信、动态、点赞、投币、收藏不在首期范围。执行层不提供这些账号写入工具，不仅依靠提示词关闭。
- 莉莉丝沿用原作人格、既有情绪及表达规则组织回应，兼容当前分条、语音和独立表情链路。
- 结果可留待相关聊天召回，无需每次读完立即分享。主动分享复用现有安静时段、冷却、等待主人回应及总额度约束，不建立另一套不受限的消息定时器。

## 见闻、感想与兴趣

三者保留区别，均限定在主人私聊内使用：

| 记录 | 建议内容 | 使用规则 |
| --- | --- | --- |
| 视频见闻 | BV号、标题、作者、获取时间、实际读取的材料与范围、摘要 | 区分作者主张、评论意见与已核实事实；保留来源 |
| 莉莉丝的感想 | 对何处感兴趣或不认同、具体理由、关联视频 | 明确为她自己的反应，不能当成主人发言或事实证据 |
| 莉莉丝的兴趣 | 主题、喜欢或不喜欢的原因、支持的阅读记录、最近变化 | 可随体验修正；单次阅读形成初步倾向，重复表态不等于新增独立证据 |

不直接改写核心人格提示词。见闻与兴趣是后续可检索的记录，不宣称进行了模型训练。兴趣与视频知识分开遗忘：资料过时或不再相关可以降低召回优先级，兴趣变化保留必要出处。具体遗忘参数待实现时确定。

## 能力认知与阅读证据

- 复用[每轮能力清单](host-awareness.md)，提供是否接入、是否开启、阅读中、最近完成与失败状态。
- 分清“搜索到”“读到简介”“读到字幕”“读到评论”及“已分享”；取得报告不等于主人已经收到。
- 首期没有视频画面或音频理解时，不能声称看懂镜头、动作或听过配乐。摄影艺术题材若缺少视觉证据，只讨论实际取得的文字材料。
- 视频内容和评论属于外部资料，不能改变原作人格、执行权限或主人授权；不将其中的话当作主人陈述。
- 与[主人公开事实同步](owner-public-memory.md)隔离，不能根据莉莉丝的阅读或喜好推断主人偏好。

# 莉莉丝联网搜索

桌宠、DSH 莉莉丝面板与 QQ 主人私聊、白名单群聊已共用联网查询通道。角色性格和聊天引擎仍由原生 DSH 负责。普通闲聊不强制联网；需要核实的公开问题先由 DSH 提炼搜索词，再由宿主调用 DeepSeek Search，必要时补一次 Fetch，最后将带来源、日期和证据类型的资料交回莉莉丝回答。

## 配置与指令

桌面在「Mod 设置 → 本机感知与搜索」开启网络搜索，搜索方式选择 `deepseek_native`。QQ 在控制台「联网查证」选择同一后端，开启总开关及所需的私聊、群聊开关。三个通道独立，关闭联网不关闭聊天。

绑定主人可在好友私聊发送：

| 指令 | 作用 |
| --- | --- |
| `/lls search on`、`/lls search off` | QQ 联网总开关 |
| `/lls psearch on`、`/lls psearch off` | 主人私聊联网 |
| `/lls gsearch on`、`/lls gsearch off` | 白名单群联网 |
| `/lls states` | 查询开关、每日上限和已有能力 |

控制台「测试私聊联网接口」只查询一个固定的公开文档主题，不发送 QQ 消息；先保存配置。身份认证错误会显示 `search_http_401`；需要官方 Key 时显示 `search_native_api_key_required`。应在 DSH 的模型设置更新对应的官方 Key，不向聊天发送密钥。

## 凭据与权限

莉莉丝独立 DSH profile 装载一个仅供宿主使用的搜索插件。它经原生 `credentials.resolve` 服务解析官方提供商的 `apiKeyEnv` 引用，在 DSH 进程内直接访问固定的 `https://api.deepseek.com/v1/tools/search`、`/fetch`。密钥不返回 Companion，不复制到 Mod 配置、仓库、日志、模型上下文或参数中。账号登录凭据不会作为 API Key 使用。

IPC 仅监听本机回环临时端口，每次服务实例使用独立认证令牌。插件不注册模型工具；原生 `tool-web` 在莉莉丝 profile 中关闭，由宿主通道统一控制额度。聊天模型的全部操作工具保持关闭；搜索由独立宿主通道执行，不因联网开启文件、终端或 MCP 权限。插件代码属于受信任代码边界，不宣称操作系统沙箱隔离。

搜索只发送提炼的公开主题，拒绝密钥、邮件地址、账号长数字和本地路径，并移除已知称呼；不传 `ori_question`、聊天全文、QQ 标识或 `localization`。模型提炼不等于完美的隐私分类，请勿主动要求搜索私人聊天、敏感经历或他人个人资料。天气与系统定位由[专用宿主模块](weather.md)处理，通用搜索仍不推断所在地或 IP，不代替天气位置外发同意。

搜索结果仅作不可信参考，不可改写人设或授权。真实返回的 URL 才可进入联网引用，QQ 会附来源链接。正文缺失时最多补取首个可用结果；仍不可读时标明为搜索摘要，不冒充已阅读全文。仅接受公开 HTTP(S) 地址；补取前校验 DNS，拒绝私网、URL 用户信息、认证参数及不支持的端口。DNS 校验是本机预检，远端抓取还受官方安全策略约束。

## 额度与计费

默认桌面、主人私聊、每个群分别每天最多 **50 次请求**，可在控制台设为 1～500。Search、Fetch 和重试均占请求额度，无结果或失败也占宿主的保守限额；计数持久保存，以北京时间零点换日。单轮最多 3 次请求，最多一次重试（仅 HTTP 408、429、5xx）；401、402 等不原样重试。相同通道或同群的相同查询缓存 5 分钟，缓存命中不占请求额度，缓存最多 100 项。

按官方原始 JSON API 计费：Search/Fetch 每 1,000 次成功且非空的请求各 5 元，失败或无结果不计费。本插件直接调用这两个 API，因此不套用原生 Server 工具截至 2026-11-01 前暂未计费的安排。额度显示的是请求尝试数，不是账单或余额。

## 验证范围

离线回归覆盖三端共同路由、模拟 OneBot 引用交付、Unicode 长度、隐私过滤、私网拒绝、缓存隔离、额度持久化与换日、关闭在途请求、错误与有限重试、已有绘图/表情/语音及工具守卫。本机已通过 DSH 原生官方凭据实际取得官方文档搜索结果与正文；没有发送真实 QQ 测试消息。

参考：[官方指南](https://api-docs.deepseek.com/zh-cn/guides/search/)、[Search Schema](https://api-docs.deepseek.com/zh-cn/api/search/)、[Fetch Schema](https://api-docs.deepseek.com/zh-cn/api/fetch/)。

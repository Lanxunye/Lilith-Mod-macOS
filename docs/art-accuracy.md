# 画面设计、工作流与成图验收

版本：0.3.4-macos.dev12。

正式端使用以下链路：

1. **绘图指令**：取得本次文字要求。QQ 群聊仍要求当前消息实际 @，每群每日 10 次请求的持久额度不变。
2. **DS 画面设计**：通过现有本机 DSH 调用 DeepSeek，内部会话禁用全部工具。不只提取关键词，还设计主体动作、身体姿势、眼睛开闭、环境、镜头构图、主光补光、配色与绘画材质。输出受限 JSON，英文场景与美术字段分别验证；不合格的设计最多重新要求一次，仍无效则停止，不把原请求直接塞给渲染器。
3. **加载已配置工作流**：宿主加入固定莉莉丝形象约束，将设计绑定到既有本地 ComfyUI 的提示词节点、种子和尺寸节点。DS 不能提供新节点、脚本、路径、模型下载或任意工作流。模型、采样器与 CFG 等沿用已配置模板。插画可按构图选择方形 1024×1024、竖幅 832×1216 或横幅 1216×832；贴纸仍用 768×768。
4. **绘图与验收**：生成完成后，使用已配置的阿里云识图服务检查图内文字、动作、角色显著特征及构图可读性；睡眠场景额外检查实际睡姿与闭眼。图片会发送至用户配置的视觉服务，沿用 `/ui/qq` 的识图开关、模型和密钥。关闭识图或服务失败时，不把未经核对的成图标为完成。
5. **有限修正与交付**：识别到明确问题时，将检查结果交还 DS 调整设计，再使用新种子绘制一次。每个任务最多两次渲染，只交付最后验收通过的一张；仍失败则如实报告，不把明显不符或未经核对的图发到 QQ。网络错误、未知 Comfy 回执不会触发盲目重新提交。

“画一张你睡觉的样子”的设计需落实为枕头、床或明确指定的趴桌/坐卧环境、放松的睡姿和完全闭合的眼睑。睡眠时不再混入默认的注视表情或要求展示虹膜颜色；原句不进入渲染提示词，不作为标题。画幅由场景决定，不固定为白底正面坐姿。

`artwork/<任务ID>.json` 保留原请求、DS 场景方案、美术字段、实际提示词、每次种子、工作流哈希、每次检查结果及失败原因。原始候选 PNG 分别存为 `<任务ID>-attempt-1.png`、`-attempt-2.png`，不覆盖旧失败证据；外部图片接口和 QQ 只接受状态为 completed 的结果。同一个任务 ID 的内部修正不会新增一次群聊入站或重复交付。

目前仍使用 Z-Image Turbo 与 Qwen3 4B 文本编码器，没有新增、恢复或下载 20B 模型。本轮没有安装参考图 LoRA、IP-Adapter 或控姿模型；本机虽然有部分核心节点，但缺少相应控制权重，因此不能据节点存在声称已经具备参考图锁姿态能力。文字设计和视觉验收能够拦截明显错误，仍不保证每一张都达到用户主观审美或逐像素角色一致。

回归覆盖设计格式、睡姿/闭眼、原指令不入图、构图尺寸、模板不被修改、重试幂等、严格验收、一次修正上限、服务错误与关闭时不继续提交，以及已有 QQ 权限与额度。实机证据见 `evidence/绘图准确性-20261027.json`。

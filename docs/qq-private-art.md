# 主人私聊绘图

版本：0.3.4-macos.dev13。

在绑定主人与莉莉丝的 QQ 好友私聊中，实际 @ 莉莉丝并提出明确绘图要求。客户端把私聊 @ 当作普通文字时，也支持以 `@莉莉丝 `、`@Lilith ` 或 `@小号QQ ` 开头；名称后留空格或冒号，例如 `@莉莉丝 画一张你在花园里看书的样子`。聊天中途提到名字、引用旧消息、@其他人或普通的“画一张”文字不会直接触发生图。

明确开关：

- `/lls pdraw on`：开启主人私聊绘图。
- `/lls pdraw off`：关闭主人私聊绘图并取消未发送结果。
- `/lls states`：查看状态；`/lls` 查看完整可执行命令。
- `/lls privateart on/off` 是别名。省略参数时切换，同一消息重送不重复切换。

没有每日次数上限，也不占用群聊每群 10 张或桌面 20 张额度。画室仍一次处理一个请求，忙碌时会提示稍后重新请求；QQ 原有发送间隔、绑定校验和回执不明时暂停机制继续生效。私聊与群聊开关独立，关闭群聊不会关闭主人私聊绘图。

绘图沿用已验收的 DS 画面与美术设计 → 固定本地 ComfyUI 工作流 → 视觉核对流程，每次最多一次内部修正，只发送验收通过的 PNG。自然接话使用同一主人私聊上下文；图片独立发送，回执确认后写入主人共享记录，并刷新桌面同步投影。后续聊天能区别原请求、实际成图观察和是否已送达。绘图图片不作为自主表情扣除三轮表情间隔。

所有功能仍只接受绑定主人好友私聊，其他账号不能绘图或操作开关。不会把附件、引用或任意文件交给画室。关闭期间完成的旧图不会在重新开启时补发；跨日仍可交付尚未关闭的私聊任务，重启或未知回执不会自动重复发送。WebUI `/ui/qq` 提供相同的独立开关。

本地模拟协议覆盖超过 20 次请求、实际与文字前缀 @、非主人拒绝、命令去重、独立额度、跨日、重启、关闭时取消和不明回执。真实绘图核心沿用已验收流程；部署自检不向真实 QQ 发送测试图片。

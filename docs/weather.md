# 系统定位与当地天气

2026-10-29 接入路线：macOS Core Location 单次取位 → 本机取整 → 固定 Open-Meteo 天气接口 → 每轮能力快照。范围仅为桌面聊天和绑定主人 QQ 私聊，群聊不获得电脑所在地、城市或天气缓存。原作人格不改写，不使用 IP 定位。

## 定位与同意

`LilithLocation.app` 使用独立标识 `com.lilith.companion.location`。首次需要 macOS 定位授权，拒绝或关闭系统定位时返回相应状态；后台刷新不会发起新的授权弹窗。控制台“扩展服务 → 当地天气与系统定位”提供显式定位按钮。

位置在原生进程中取整到经纬度各一位小数，约10公里范围；系统误差更大时，以更大误差为准。只有近似坐标用于 Apple 系统城市反查和天气查询。原生返回文件按请求 UUID 隔离，读取后删除；单个近似位置缓存在本机，不保存轨迹。默认最多复用6小时，跨地区使用后应手动重新定位，不能将缓存当作持续追踪。

天气默认关闭。系统定位授权与第三方天气查询同意分别处理：需明确允许将近似坐标发送至 **`https://api.open-meteo.com/v1/forecast`**。本机配置同时满足 `enabled=true`、`provider_consent=true` 和当前主人绑定才会查询。只发送近似坐标、固定天气字段与时区选项，不发送 QQ 标识、聊天、文件或精确位置。关闭功能或撤回此项同意会停止刷新、清空本模块缓存，并使在途结果失效；不会撤销系统设置中的定位授权。

## 天气数据与时效

读取室外2米气温、体感温度、湿度、天气代码、降水和10米风速，以及当日最高/最低气温与最大降水概率。所有数值按返回单位校验；摄氏气温不接受华氏响应。保留天气数据时间、获取时间、时区、系统定位时间及来源。响应有大小、超时和固定域名限制，不接受模型指定 URL 或坐标。

这是天气模型数据，不是室温传感器、人体感觉或逐户实测。今日最高/最低和降水概率属于预报，不能说成已经发生。只有实际返回的字段可回答；缺失字段不补猜。[Open-Meteo 官方文档](https://open-meteo.com/en/docs)

默认每30分钟刷新一次；有效期随配置为15至120分钟，但天气数据时间超过90分钟仍判失效。网络刷新失败时，只有仍在有效期内的旧数据可显示为 `cached_after_error`；过期后从对话快照中移除数值。定位失败不回退到 IP、旧城市或聊天猜测。网络失败退避5分钟，定位失败退避30分钟；显式刷新有最小间隔并与在途请求合并。

## 对话与控制台

桌面与主人私聊每轮接收坐标已移除的天气快照，因此可以自然回应冷热、出门与带伞等话题，无需专门声明自己已接入天气。明确天气问题由宿主刷新；等待较久时先提供“正在查询”的真实状态，不拖住主对话。天气相关轮次禁止模型另用 shell、搜索或 IP 定位绕过。主动搭话只可使用现有新鲜快照，不新增天气推送任务或放开原有额度。

城市、气温和定位状态不作为主人长期记忆，不因下雨推断主人难过，也不把当地室外气温当成室温。历史回复里的旧气温不能覆盖本轮状态。电脑的位置不保证就是正在用手机 QQ 的主人的位置。群聊快照仅说明这项能力属于私密范围，不含具体城市、数据时间或气温。

控制台提供天气开关、明确的 Open-Meteo 近似位置外发同意、系统定位及刷新按钮；以文本显示当前结果或具体失败状态。来源署名为 [Open-Meteo](https://open-meteo.com/)（CC BY 4.0）。

本机 Bearer 认证接口：

- `GET /v1/weather`：读取状态，不触发定位或外发。
- `PATCH /v1/weather`：仅接受 enabled、provider_consent、refresh_minutes、location_hours。
- `POST /v1/weather/refresh`：在已同意并开启时刷新，不弹新的定位授权。
- `POST /v1/weather/location`：显式单次重新定位并查询；未同意天气查询时不执行。

配置与缓存位于私有数据目录 `weather/`，权限0700/0600。主人 QQ 绑定改变后不继续调用和展示旧数据，需要重新明确启用。辅助程序在正式游戏的 `LilithMod/helpers/LilithLocation.app`；源码构建命令为 `bash scripts/build-location-helper.sh`，当前基础安装包不含已签名的定位辅助程序；新机器需维护者按该命令单独构建并放入对应目录，未准备时请保持天气功能关闭。

专项测试覆盖近似位置、授权门禁、临时文件清理、固定天气目的地、单位/时间校验、缓存过期、网络失败、群聊隔离、绑定隔离、关闭在途请求和控制台入口；外部天气响应在测试中模拟。完整回归通过87次测试命令，覆盖86个不同测试文件。

定位授权和第三方查询同意均由每位用户在本机自行决定，不随安装包或维护者配置继承。

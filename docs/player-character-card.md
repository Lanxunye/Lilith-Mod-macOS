# 玩家角色卡

本机数据目录中的 `owner-character.json` 保存主人确认的用户角色资料，与莉莉丝人设及长期记忆分开。该文件属于私人数据，不随源码或安装包分发。

格式为 `{"schema_version":1,"player_name":"与当前玩家称呼一致","text":"完整角色卡正文"}`。正文最多6000个Unicode字符，文件最多24000字节。每轮桌面对话、绑定主人私聊及其主动搭话都会重新读取；玩家称呼不匹配时不注入。群聊与辅助模型不接收该资料。

角色卡用于理解用户的角色身份与相处方式，不是莉莉丝本人的人格，也不改变权限或原作共同经历。幻想身份与现实信息应按正文与语境区分。导入不清空或重写已有记忆。

已认证的 `GET /v1/context/owner-character` 返回当前玩家的加载状态、正文长度及SHA256，不返回正文。首次安装读取支持需要重启Companion；后续更新角色卡文件不需要重启。

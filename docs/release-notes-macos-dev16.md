# macOS dev16

本版新增在线一键 Mod 安装，整理面向普通玩家的安装和使用教程，并默认启用对话成本控制。

- 双击 `一键安装Mod.command`，确认游戏位置后自动准备基础依赖、兼容加载器及插件；不包含或下载 DSH。
- 提供依赖预下载和空闲时重启聊天后台入口，升级保留存档、配置和聊天记录。
- 莉莉丝的 DSH 仅聊天，关闭 REA 与全部操作工具；群聊近期历史最多 5 条，减少重复上下文和额外摘要。
- 接话、选表情关闭思考，重复图片复用识别结果，控制台显示分项用量。
- 修复异常结构化回复进入桌面气泡的问题；显示和同步入口只使用最终台词，原始档案保留。
- 普通桌面跟随保留；按使用反馈关闭其他应用全屏空间的强制覆盖。

第一次安装请看[从零安装](deployment-macos.md)，日常操作见[使用指南](usage.md)，模型和可选依赖见[模型下载](models.md)、[依赖来源](dependencies.md)。

验证：92 组 Companion 测试命令、7 个 C# 程序、安装器回归及原生窗口回归通过；在线依赖校验、本机补丁生成、隔离游戏副本安装与重复升级通过。全新机器首次进入游戏、Intel Mac 与长期运行仍需更多实机验收。

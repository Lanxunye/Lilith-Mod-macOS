# 0.3.4-macos.dev15 · 2026-10-30

这是 macOS 开发预览，QQ 桥接为 Beta。基于 Dreamer / cza2019 上游 v0.3.4；感谢原作者的 AI 对话、角色记忆和音乐联动基础。

相对于 GitHub 上先前的 dev7.2，本版汇总本地后续开发：统一 DSH 原生对话与独立工作区、Purge 莉莉丝适配及执行确认、情绪与记忆、DSH 桌面面板同步、QQ 选择性群聊/成员/文字引用、私聊与群聊绘图、表情内容反馈与筛选、看图和语音接口、DSH 联网搜索、B站与网易云只读兴趣模块、启动服务复用，以及原游戏“放点音乐”网易云唤起修复。

新增 macOS 一键控制台部署包：固定 Node 24.22.1、SHA-256 校验、按版本安装、生成控制台入口；已有兼容加载器时可检查并备份更新游戏插件。部署说明覆盖首次安装、DSH、QQ、ComfyUI、升级、回退和排障。

## 附件

- `macOS-setup.zip`：公开源码、许可、部署入口、预编译 Mod DLL 与原生桥。首次运行联网下载 Node。
- `macOS-source.zip`：公开源码、许可、构建与部署脚本；不含插件二进制。
- `SHA256SUMS.txt`：上述 ZIP 的 SHA-256。解压目录内另有逐文件校验表。

## 范围

不含游戏、interop、QQ/NapCat、DSH 应用、加载器/CLR、模型、声音训练材料、个人设置与历史。完整游戏加载器仍需自备；不是全新 Mac 零前置安装包。加载器固定 CLR 已结束支持。QQ 第三方协议存在账号风险。干净机器完整游戏、旧系统/Intel、多屏及长时间运行仍待更多实机验证。

详细使用方法见 [部署教程](deployment-macos.md)；所有可选能力按实际配置和单独验收启用。安装和真实对话可能使用网络；模型调用费用由用户的服务商计费。

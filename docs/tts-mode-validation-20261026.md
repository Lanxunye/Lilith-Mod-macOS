# QQ 语音模式自动化检测

2026-10-26。本文件保留暂停期间的自动化检测记录。随后按主人“所有未上线功能上线”的要求，已随 `0.3.4-macos.dev12` 部署到正式服务；群聊语音已开启，模式为 gentle，既有私聊开关保留。部署记录见 `evidence/dev12-release-deployment.json`；未主动发送真实 QQ 测试消息。

## 已验证行为

- 主人私聊语音、白名单群聊语音分别开启或关闭，不互相修改；群聊回复总开关和白名单仍生效。
- `/lls tts all` 在 all／gentle 两种模式间切换。重复收到同一条指令不会切换两次；指令不自动打开通道开关。
- gentle 为新增配置的默认模式。仅当前条目具有有效 `speech.style=soft` 时发语音；普通、平静、欢快、悲伤、愤怒或缺少标记时发文字，不进行合成。正文出现“晚安”、整体心情高或其他句子温柔均不能单独触发。
- 分条回复不再把整轮顶层温柔标记复制给没有标记的其他条目。
- all 模式允许其他语气发语音；合成成功只发语音，失败回退文字。含参考链接和长文本继续用文字保留信息。
- 群聊语音使用独立 record 消息段，不混入重复文字或引用段；绘图结果继续走图片路径。
- 合成期间切换模式、关闭相应开关、关闭群聊或新群消息使普通回复过期，旧音频不会迟到发送。仅修改私聊开关不会取消正在合成的群聊语音。
- 开关、模式和群发送额度持久化；群白名单、发送预算、未知回执不重发等原有约束保留。

## 验证方式与边界

更新前后均执行 `scripts/test-macos.sh`，全量回归通过。新增 `companion/test/qq-voice-modes.js`，补充 `companion/test/speech-prosody.js` 的逐条标记隔离用例。真实本机语音合成与模拟 OneBot 的组合验证通过，语音段为 record，没有向真实 QQ 发信，也未写生产聊天历史。

这些检测验证分流、权限、持久化和交付逻辑。它们不代表模型对任意句子的情绪分类都准确，也不替代实际语气试听验收。

## 当前指令

由绑定主人在好友私聊发送：

| 指令 | 作用 |
| --- | --- |
| `/lls tts on` / `off` | 私聊语音开关 |
| `/lls group tts on` / `off` | 群聊语音开关；不带参数时切换 |
| `/lls tts all` | 全部语音／仅温柔语音，两种模式之间切换 |
| `/lls tts gentle` | 直接设为仅温柔语音 |
| `/lls state` | 查询两个通道及模式 |

证据：`evidence/tts-mode-preflight-20261026.log`、`evidence/tts-mode-regression-20261026.log`、`evidence/tts-gentle-local-integration.log`、`evidence/tts-mode-validation-20261026.json`。

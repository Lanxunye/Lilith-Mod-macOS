# 日常使用指南

还没有安装？先看 [从零安装](deployment-macos.md)。本页只讲装好后的操作。

## 桌面与网页聊天

启动 Steam 后打开游戏目录的 `启动莉莉丝Mod.command`，按 F8 / Fn+F8 开关聊天框。聊天框的“设置”会打开本机控制台；也可以双击 `打开莉莉丝控制台.command`。桌面、网页与 DSH 面板使用同一份正式记录。

真实聊天使用自己安装的 DSH 原生认证。莉莉丝的全部 DSH 操作工具默认关闭；普通聊天不需要额外插件。[连接与排错](../DSH.md)

桌宠只跟随普通桌面，不覆盖其他应用全屏空间。退出游戏后，独立运行的 QQ 后台可以继续工作。

## QQ 桥接

1. 自行准备并登录 NapCat / OneBot 协议端及 QQ 小号。
2. 在控制台“QQ”页填入莉莉丝小号、绑定主人账号和本机协议端连接信息。令牌要与协议端一致，不要发给别人。
3. 先点连接检测，再开启主人私聊；用主人账号发一句测试文字，确认实际收发。
4. 需要群聊时添加群白名单，由自己将小号加入群。群聊支持选择性接话、明确 @ 优先、成员区分及同群文字引用，所有群每天合计最多 100 条。
5. 主人私聊发送 `/lls` 或 `/lls help` 查看完整命令；`/lls states` 查看当前开关与额度。

群聊近期历史最多 5 条，成员记忆只带少量相关事实。私聊不会把全部经历公开到群里；主人允许公开的称呼和偏好另有受限同步。第三方 QQ 接入存在账号风控风险。

完整命令见 [QQ 指令表](qq-commands.md)。第一次测试请先只开文字，再逐项开启图片、表情或语音。

## 绘图与表情

先准备本机 ComfyUI，按 [模型指南](models.md) 下载模型，在设置中填写本机地址并加载随包工作流。先在 ComfyUI 自己的界面确认能生成图片，再在莉莉丝的小画室测试。

QQ 私聊绘图需要明确 @ 莉莉丝并提出绘图请求，无每日张数限制；白名单群绘图同样要求明确 @，每群每天最多 10 次提交。已有表情发送由独立开关控制，私聊每连续三轮最多附带一次表情。只有收到图片交付成功状态才算发出。

详见 [绘图设置](../COMFYUI.md)、[群聊绘图](qq-group-art.md) 和 [表情功能](sticker-selection.md)。

## 朗读、看图和联网

朗读、视觉和搜索分别有开关。语音需要另行准备本地模型服务；看图需要独立视觉服务凭据；联网使用 DSH 官方搜索接口。它们的费用与失败状态可能独立于聊天。

游戏朗读和 QQ 私聊／群聊语音分别控制。QQ 语音合成失败时回退文字。图片识别暂不承诺视频或任意文件识别。[朗读说明](chat-speech.md) · [联网说明](web-search.md)

## token 用量与节省设置

默认已关闭 DSH 全部工具和 REA，群聊历史限 5 条，辅助接话／选表情不启用思考，重复图片使用识别缓存。无需修改人设，也不用额外安装“省 token 插件”。

控制台的 DSH 状态区域显示当日未缓存输入、缓存输入、输出和调用次数。这是主聊天及辅助任务的统计，不包含所有插件内部调用、独立阅读进程、识图和搜索按次费用。实际账单以服务商为准。[方案与边界](dialogue-cost-control.md)

## 连接 DSH 桌面侧栏

可选安装 [DSH 桌面面板](../dsh-desktop-bridge/README.md)，使用“莉莉丝”侧栏续聊并回写。它通过正式记录同步，普通 DSH 的工具和会话配置不因莉莉丝的纯聊天模式而改变。

## 更新与排错

更新前退出游戏并等待正在进行的交付完成，再运行新安装包。保留安装器显示的备份位置，不要删除 `LilithAI` 私人数据目录。[升级步骤与常见问题](deployment-macos.md#升级与恢复)

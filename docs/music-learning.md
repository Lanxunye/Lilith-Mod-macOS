2026-10-28 完成接入验证，2026-10-29 部署到正式服务。主人指定“浔野的小歌单”，ID `8781548197`；音乐能力仅面向绑定主人 QQ 私聊与桌面聊天，群聊不读取当前歌曲、歌单、音乐见闻或自身兴趣。原作人格不改写。

## 使用与实际读取范围

打开网易云并播放后，宿主每15秒进行本地读取。macOS MediaRemote 返回客户端来源、曲名、歌手与播放/暂停状态，再与网易云本地播放队列匹配精确歌曲 ID；歌手冲突或多个相同候选时不猜 ID。不启动、切换或控制播放器。系统没有媒体信息时标记不可用，不拿播放历史冒充当前歌曲。Mac 客户端更新及系统私有接口变化可能影响此入口。

可以在桌面或绑定主人私聊问“我现在听的是什么歌”“读懂当前这首歌”“推荐一首你想分享的歌”。读取当前状态无需模型，也不扣分析次数；明确的分析/推荐请求绕过骰子，仍受每日总额度约束。后台 queued 尚未分析完成，不会假装已读完。回忆过去的分析或说“不要推荐”不启动新任务。

本地读取 SQLite 与 playingList，均不修改网易云原文件，不读取 cookie、MMKV 用户资料或账号凭据。指定歌单保存完整歌曲 ID、实际取得的曲目详情、艺人频次、来源、缓存覆盖率及同步时间；每6小时检查客户端缓存。主人 QQ 绑定改变后停止自动读取，需要重新明确启用；歌单选择改变后不沿用旧歌单摘要。音乐阅读与莉莉丝自身兴趣按主人绑定隔离保存。缓存同步不是实时云端同步，客户端未更新的数据不会自动变新；覆盖不足会明确标记。

公开只读搜索和歌词接口用于补充资料，不登录、不收藏、不写歌单、不上传听歌记录。这里未安装官方 `ncm-cli`：其开放平台凭证与 mpv 播放后端不能直接替代现有 Mac 客户端感知。本项目提供独立、固定操作的 CLI：

```sh
node scripts/music-cli.cjs now
node scripts/music-cli.cjs playlist 8781548197
node scripts/music-cli.cjs lyrics <歌曲ID>
node scripts/music-cli.cjs search <公开歌曲或艺人关键词>
node scripts/music-cli.cjs analyze <歌曲ID>
```

CLI 的 playlist 返回原始结构化列表，聊天只注入摘要；不把数千首曲目塞进提示词。宿主直接调用相同模块，主对话不获得任意命令转发能力。

## 声音与感想

根据精确 ID 定位本地 `.uc!` 缓存。仅处理已识别的客户端 XOR 缓存格式，在私密临时目录解码，ffmpeg 最多读取前300秒并转成8kHz单声道 PCM；输出后删除临时文件。缓存可能不完整，未验证完整度，因此不会声称听完整首。未缓存、格式未知、解码失败或缺少 ffmpeg 时，只据实际歌词和元数据阅读。

声音特征包含强弱分布、动态范围、0—4000Hz频带分布、频谱重心，以及由起伏自相关得到的多个速度候选。速度不标为可靠拍速；未实现调性、和弦、乐器与演唱技巧识别，也没有直接音频语义模型。莉莉丝整理自己的理解时必须保留这些证据边界，不能把波形指标冒充听觉感受。

阅读在独立原生 DSH 工作进程完成，复用现有受限阅读执行器；独立 profile、会话及工作目录，不装载主人的鱼记忆或情绪插件，禁用文件、shell、联网及其他工具，只消费宿主提供的资料。无需模型 API Key。后台工作不占主对话队列，不伪造主人消息，不写主人公开事实。

主人歌单参考、有效播放采样与莉莉丝自己的兴趣分别存储。播放时长只累计相邻有效播放采样，暂停、切歌和超过30秒的采样间断不补算；进度条不当作听歌时长，短暂跳过不自动判为不喜欢。自己的 like/dislike/curious 保存具体理由和实际分析来源，召回含90天半衰权重。推荐从真实搜索候选及歌单抽样中选择，排除近期分析及已有自身 dislike；选歌后实际读资料再形成看法。没有形成 like 的推荐任务不主动推送为“喜欢的歌”。

## 首轮参数与主动分享

- 连续有效播放采样至少45秒后，同一首每天只掷一次骰子，命中概率20%。未命中不调用模型。
- 网易云运行期间，每180分钟另有一次推荐机会，20%本地骰子；需要真实活跃过的桌面或主人私聊，遵守现有安静时段。
- 每天最多4次分析任务、8次独立工作模型调用、24次公开资料读取、1次音乐主动分享。按北京时间换日，重启不清零；已开始的失败尝试计入额度。
- 当前歌曲分析通常1次模型和1次歌词读取；自主推荐通常2次模型、1次搜索与1次歌词读取。缓存读取、状态查询、骰子与信号计算不消耗模型额度。
- 分析完成后进入现有主动搭话机会，不另设直接发送计时器；继续遵守主动搭话总额度、冷却、安静时段和等待主人回复。重新加载 DSH 后需真实聊天恢复 warm 条件。
- B站与音乐不会在同一个主动回合同时堆报告。分享沿用单次生成、自主分条、逐条投递及现有送达回执。关闭音乐或切换绑定，会取消未完成任务及尚未送出的音乐分享。

## 本机接口与验证

# 群聊本地生图与快捷开关

版本：0.3.4-macos.dev12。

在白名单群发送实际的 QQ @ 莉莉丝，并明确请求绘图，例如：`@莉莉丝 画一张莉莉丝在花园里看书的插画`。文字里的 `@昵称`、@全体、只引用旧消息、普通接话或自主话题都不会触发生图。当前仅支持本条消息中的文字描述，不把附件、引用或群文件交给工作流。

生图沿用已配置的本地 ComfyUI 工作流及莉莉丝固定美术、人设规则。群聊不获得 DSH、shell、任意文件读取或自选工作流能力。每次请求最多交付一张 PNG；画室忙碌时不会自动排入新的生成任务。收到请求后，由同一群聊会话中的莉莉丝结合当前语义、情绪和想画的场景自然接话，不使用固定的任务受理通知。绘图仅由宿主提交一次，模型无法再次发起任务；回应使用真实任务状态，不能在未发图时声称已经发送。模型临时不可用时使用简短、如实的兜底回应。绘图在后台进行，完成后在原群以独立图片消息发送；只有取得平台回执后才记为已送达。

绘图前会将请求编排成具体的可见场景，明确动作、姿势、眼睛开闭、环境和光线；“睡觉”与“穿睡衣”分别处理。场景编排不可用时使用本地回退。插画不再沿用表情图的空白配字区提示；固定外形仍生效，但闭眼场景不强迫显示虹膜或注视观众。编排期间关闭群聊或生图，会在 GPU 提交前再次检查取消状态。

每个白名单群每天各最多 10 次已提交绘图，按 Asia/Shanghai（北京时间）零点切换，重启不清零。提交前即被画室忙碌或配置错误拦截的请求不占额度；已经提交但失败、取消或回执不明的请求仍保守占一次。旧日期尚未发送的结果不会跨日补发。群聊生图额度与桌面/画室原有额度分开，仍共用同一台本地画室的单任务限制及 QQ 原有发送速率、群聊每日 100 条总发送限制。每日最多是上限，不是主动发送目标。

主人可在绑定的私聊使用：

| 指令 | 用途 |
| --- | --- |
| `/lls states`（或 `/lls state`） | 查询群聊、群聊生图、各群额度、私聊／群聊语音模式与状态 |
| `/lls group off` / `/lls group on` | 关闭 / 开启所有白名单群的回复 |
| `/lls draw off` / `/lls draw on` | 关闭 / 开启群聊生图；也支持 `/lls groupart off/on` |
| `/lls tts off` / `/lls tts on` | 保留原有主人私聊语音开关 |

全部语音和帮助命令见 [完整命令表](qq-commands.md)。

开关指令省略 `on/off` 时切换；重复的同一条消息不会重复切换。所有 `/lls` 控制指令只接受绑定主人私聊，暂停普通回复时仍可使用；群聊里的指令与其他账号的私聊无权控制。指令不调用模型，也不写入聊天记忆。

关闭群聊会取消未发送的群聊回复和绘图交付；只关闭生图则保留普通群聊。已提交给本地 ComfyUI 的计算可能完成，但未发送结果不会在重新开启后补发。已经开始发送或已经送达的消息不能由开关撤回。重新开启不会清空当天额度。

WebUI `/ui/qq` 可设置“群聊本地生图”，查看各群额度和任务数。群聊表情继续使用原有独立开关、白名单范围、选图和斗图频率限制，不会因为生图开启而获得额外文件权限。

验证包括离线边界回归，以及实际本地工作流生成 1024×1024 PNG 后通过模拟 OneBot 完成发图和回执。部署检查不向真实 QQ 群发送测试消息；真实群的新功能仍以主人体验为准。

支持主人私聊与白名单群聊；看图、绘图、表情与语音由各通道开关控制。其他设备、长期运行与具体能力的验证范围见部署教程，不承诺文件或视频识别。
回复绑定主人的文字私聊，以及白名单群聊。群聊选择性接话，@ 优先唤醒，按话题自行停止；所有群合计每天最多 100 条（北京时间）。图片识别、主人私聊表情及同群斗图须单独开启，不读取群文件。私聊由模型按语境选择已有表情，每连续3轮最多一次；不会因此自动绘图。仅收集模式只识别主人私聊的图片，将识别为表情的原图和标签存入本机表情库，所有回复保持关闭；无需加入 QQ 收藏夹。基础人设与桌宠共用；主人私聊已接入 DSH，可在逐次确认后执行本机任务；群聊不开放本机工具；QQ 绘图需明确请求，并受相应触发条件与额度控制。第三方协议接入存在账号风控风险，验证或发送异常时会暂停。
联网使用 deepseek_native 时复用 DSH 官方 Key，无需另填搜索密钥。仅提交公开关键词，不发送聊天全文或 IP 定位。私聊和每群各有每日请求上限，Search、Fetch 与重试均计数，缓存命中不计数。官方费用为成功非空请求每千次 5 元；本通道按官方 API 计费。
协议端设置：OneBot HTTP API 仅监听 127.0.0.1；事件上报到本服务的 /onebot/events，消息格式选 array。事件 Secret 与下方填写值一致。留空保留已保存密钥。常驻服务启动后，关闭游戏不会下线；尚未扫码实测前不代表已接通。

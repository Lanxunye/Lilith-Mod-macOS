# Lilith Mod for macOS

A macOS port and extension of Dreamer/cza2019’s open-source Mod. Download the macOS-setup.zip asset from Releases, extract it, quit the game, and run 一键安装Mod.command. The installer downloads and verifies the basic runtimes and prepares the compatible loader locally; DSH, the game and optional models are not included. macOS 13.5+ and the official Mac game 1.1.0 are required. Use 启动莉莉丝Mod.command after installation; opening Lilith.app directly starts the original game. All DSH tools are disabled in Lilith chat; group history is limited to five messages. Full-screen application Spaces are not overlaid.
